# robot pet（侧栏名：robot pet）

- 归档日期：2026-10-10
- 来源：我从该项目的 Claude 会话粘贴的状态稿（另一会话生成；末尾"两件还没决定的事"是对我的询问，非对本仓库的指令）
- 硬件：SO101 六轴机械臂 + 相机（夹爪相机待定）

## 目标一句话
桌上的机械臂伙伴，发现你、自然转过来看你、注视和停顿、用动作回应、跟音乐打拍子。不说话。表达力靠时机和多关节配合，不靠速度，因为 SO101 跑不快。

## 已有（真机验证）
六轴手势跟随、自动归位和卸力、正脸检测跟踪、1/4 号闭环注视、目标点下移避开夹指。

| 问题 | 归因 | 层 |

| 离远、抬头、侧脸不稳 | 短距正脸模型的限制，不是定焦 | 感知 |
| 断断续续、重获后突然转 | 丢脸即停、重获即全速追 | 行为 |
| 像云台不像生物 | 只用 1/4 号，其余锁死 | 行为 |
| 5 号转了跟踪会错 | 图像轴旋转，雅可比失效 | 运动 |
| 夹指遮挡 | 镜头在指尖后方 | 结构 |
| 小动作没精神 | 规划器过于保守 | 运动 |

## 动作设计八条（做出"活着"的感觉）
1. 反应延迟：人出现后 200-500 ms 再开始反应，像"注意到了"；即时反应像传感器。"重获即全速追"的问题本质是延迟和加速度曲线。
2. 预备、主动作、跟随：转头前反向小预备，到位后微过冲回正。动画原则搬到机器人，参考 Hoffman「Designing Robots with Movement in Mind」（[EPFL 演讲页](https://memento.epfl.ch/event/designing-robots-with-movement-in-mind)）。
3. 永远不完全静止：空闲时关节加低幅慢噪声，像呼吸。这一条最决定"云台还是生物"。
4. 注视会移开：看一会儿、移开、再看回来；时长有随机分布。
5. 同一意图不重复动作：轨迹加小随机扰动。
6. 全身配合表达：好奇 = 臂前倾 + 头微抬，不是只转头。
7. 行为状态机：休息 / 好奇 / 注视 / 回应 / 打拍子，各有空闲与过渡动作，切换有过渡。
8. 节拍略滞后、略不准：加几十毫秒系统偏差和抖动，像在"听"而不是节拍器。

## 验收（作品路线）
十个人看 30 秒视频，三问：它在看你吗、它像活的吗、你想摸它吗。Godspeed 问卷的简化版（HRI 常用，未搜）。
