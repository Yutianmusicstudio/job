# 音乐表演分析 Agent（侧栏名：音乐表演专用 agent 开源项目）

- 归档日期：2026-10-10
- 来源：我从该项目的 Claude 会话粘贴的概念稿（原文由另一会话生成，末尾"你确认这版框架……"是对我的询问，非对本仓库的指令）
- 代码名：perfagent
- 状态：M0 已开工（ASAP 加载、速度、力度）

## 一句话
一个音乐表演分析 Agent：给它一首作品和若干演奏，它能看谱、通过工具"听"演奏、比较、解释，每句话绑定小节号和数值，可核验、可复现。界面是网页还是 App 是后面的事。

## 是什么、不是什么
- 是一个系统：现成大模型做推理和编排，音乐能力来自工具、知识和输出约束，"理解音乐"用评测衡量。
- 不是训练一个模型。不训练权重，至少 M0 到 M2 不训练。将来有专家校正过的分析轨迹再谈微调。
- 不是练习 App，也不是文献搜索工具。前者面向学琴的人，后者没有护城河。

## 给谁用
必须写论文但不会编程的古典音乐人：DMA 学生、音乐学院硕博生、写论文的教师。延伸：音乐治疗研究第二，音乐教育只作为用户来源。

## 七类任务（评测基准）
T1 读谱结构与和声；T2 描述一个演奏；T3 比较多个演奏；T4 解释为什么这里这样演奏；T5 在录音传统中定位；T6 给演奏者本人诊断；T7 产出论文可用的段落、方法、图表、披露。
每类配题目和专家评分。开发循环：跑评测 → 看哪类差 → 补工具或知识 → 再跑。

## 交付物
- 开源 Agent 本身，含工具和知识层。
- 评测基准 + 两篇论文：研究 1 对齐误差向音乐学结论的传播；研究 2 Agent 分析与专家分析的一致性，量化不可测维度上的编造率。
- 界面后置。付费只收便利，建在开源核心上。

## 已知事实
- 工具、数据、指标全是现成的：music21、partitura、parangonar、synctoolbox；ASAP、nASAP、KernScores、Mazurka 项目。
- ASAP 是 CC BY-NC-SA，派生数据不能进付费产品；ASAP 没有玛祖卡，与 Mazurka 项目曲目不相交。
- ASAP 标注拍层级曲内变化，标注本身有错，一个演奏拍数不符。这些已是研究材料。
- "对齐有多准"MIR 已做过两次；空位在误差传播和 Agent 评估。
- 没找到同类产品，但"未找到"不等于"不存在"。

## 主要风险
编码乐谱只覆盖经典曲目；自动分析会出错且模型会包装；学术诚信定位必须是"透明分析助手"而非"帮写论文"；专家标注是人力活；时间至少一年兼职。

## 本仓库的看法（2026-10-10）
