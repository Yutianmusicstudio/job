# 混合接口系统：VR + 脑电 + 肌电 + 机械臂（个人项目）

- 建档：2026-11-28。来源：我和 Claude（博士线）的讨论；我决定先自己把整套系统搭起来。
- 占用槽位：实验室外唯一的个人项目（并入原 robot pet / 机械臂项目）。
- 一句话：用肌电、脑电（以后加眼动）控制机械臂和 VR 里的虚拟钢琴，并把每一步的可靠性测出来。
- 远期用途：(1) 接实验室此前肌电 / 脑电辅助弹琴没做成的地方；(2) 给 Claire 侧"想象弹琴时的信号"研究当采集设备；(3) 申博时的工科证据。

## 设计原则
1. **先打通一条最细的线，再加层。** 每一层做完才开下一层，防止又停在七成。
2. **从第一天起就是一台"采集 + 控制"两用的机器。** 所有信号带时间戳同步记录，控制用的数据同时就是研究用的数据。
3. **每一层都要有数字。** 准确率、延迟、每分钟误触发次数。这是我区别于"做了个 demo"的地方。
4. **音乐部分先用虚拟钢琴（MIDI），不让机械臂去按真琴键。** 机械臂慢，音乐要求几十毫秒的准时。机械臂演示"控制"，虚拟钢琴演示"演奏"。

## 结构
采集（肌电板、脑电头环）→ 同步总线（Lab Streaming Layer，带时间戳，可录成 XDF 文件，MNE 能直接读）→ 解码（Python）→ 指令 → 三个输出：SO101 机械臂、MIDI 虚拟钢琴、VR 头显里的画面反馈。

## 里程碑（做完标准 = 一段视频 + 一组数字 + learning/log.md 一条）
| 层 | 做什么 | 做完的标准 | 预计 |
|---|---|---|---|
| M0 | 一路肌电 → 阈值 → 机械臂夹爪开合；信号进同步总线并录下来 | 握拳十次，夹爪对十次；录到的文件能用 MNE 打开画图 | 设备到后第一个周末 |
| M1 | 2–4 路肌电 → 3–4 个手势分类 → 机械臂几个姿态 | 报告分类准确率（按次分折）和从动作到机械臂响应的延迟 | 寒假 |
| M2 | 加脑电当开关（闭眼 α 波）：开 = 允许控制，关 = 锁定 | 报告每分钟误触发次数和开关成功率 | 寒假至 1 月 |
| M3 | VR 里的虚拟钢琴：肌电触发发声（MIDI）| 测触发到发声的延迟；能跟节拍器打准四分音符 | 2 月 |
| M4 | 加眼动：眼睛提前选键，肌电在拍点触发 | 选对率、误触发率；需要带眼动的头显（设备待定）| 3 月 |
| M5 | 加音乐预判：系统知道曲子，肌电只控制"何时、多重"；再做"系统预测下几个音，人来选" | 同一段旋律，有预判和没预判的错音率对比 | 春季后半 |

M0–M2 = 原计划的"肌电 + 脑电控制机械臂"，2027-03 前出第一段视频。M3 起是往辅助演奏方向长。

## 规矩
- 电路一律电池供电，不接市电；机械臂运动范围内不放手和脸。
- 只在自己身上测。找别人测并打算发表之前，先过伦理审批（可挂在实验室或 Claire 的协议下）。
- 12 月期末、弄懂自己的论文、见 Claire 排在它前面；它是寒假的事。
- 搭 M0 的同时去问组里：之前肌电 / 脑电辅助弹琴用的什么设备、败在哪一环。问到了再决定 M3 以后怎么走。

## 2026-11-28 补：要不要加一只仿人灵巧手（待定，M2 之后再定）
- 起因：SO101 只有两指夹爪，我想 3D 打印或买一只仿人手。
- 判断：**M0–M2 不需要。** 瓶颈在解码不在执行器：肌电目前分不清单根手指（Weinberg 当年也卡在这），五指手接上去也只能做整手开合。手指级的展示先放在 VR 里的虚拟手上，零成本、无机械问题。
- 什么时候加：M1 做完、能稳定分出四五个手势之后；或需要一段更好看的展示视频时。
- 到时的选项（2026-11 检索，价格以官方为准）：Pollen Robotics 的 Amazing Hand（开源、全 3D 打印，零件成本称低于 €200，约 400 g，原配 Reachy2 手腕，接 SO101 要自己做转接）✅；ISyHand（开源，Dynamixel 电机，材料约 $1,300）✅；CRAFT hand（称低于 $600，计划开源）⚠️。LEAP Hand、ORCA hand 价格未核实。
- 先问组里：实验室做过假肢手，有没有现成能借的。
