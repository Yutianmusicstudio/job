# Wenku（macOS 文献管理软件）

- 归档日期：2026-11-27
- 来源：我粘贴的项目总结（由该项目会话生成）
- 一句话：自己用的 macOS 文献管理软件，替代 Zotero。已装在本机，版本 0.13.1（构建 27）。
- 方向：只做苹果生态，只支持 LaTeX，数据存本机，先自用，以后再考虑商业化；因此不用任何 AGPL / GPL 代码。
- 结构：文库（含阅读）、编辑器、Agent 三个工作区；AI 面板与 Agent 共用一套对话。
- 已做出：磁盘上的真实文库（每篇一个文件夹，原始 PDF 不被修改，SHA-256 校验）；PDFKit 阅读器（划选、四色高亮、下划线、批注、撤销重做、查找、记住位置、导出带批注副本）；缩放滑条；系统自带的本机翻译（划选 / 整篇、缓存、存笔记）；在线搜索（OpenAlex 为主，Crossref、arXiv 补充；按 DOI 添加；导出 BibTeX；开放获取 PDF 直接下载）；内置浏览器（可登录学校图书馆，抓取当前页文献信息）。
- 在地图上的位置：主线之外的工具，不写进研究材料；简历里只作为"能把软件做完"的一行证据。
- 状态：进行中（自用）。
