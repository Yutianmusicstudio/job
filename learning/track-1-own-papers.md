# T1：弄懂自己的两篇论文（第 1–4 周）

## 第 1–2 周：OpenMIIR 稿（Paired-trial grouping…）
五问，全部闭卷、用大白话：
1. 被试到底做了什么？一个试次长什么样？"有提示 / 无提示的想象"差在哪？
2. 从原始脑电到喂给模型的数字，中间几步？每步为什么（滤波、分窗、带功率）？
3. 配对的两个试次分到训练和验证两边，为什么分数会**低于**随机？
4. "删除配对伙伴 vs 删除非伙伴"这个对照，证明了什么？没证明什么？
5. 这篇最弱的三处是什么？审稿人会怎么问？我怎么答？

动手（每周一件）：
- 第 1 周：打开一名被试的数据，画出一个试次的原始波形和它的带功率，自己写图注。
- 第 2 周：把分折方式从"按配对"改成"按试次"，亲眼看分数掉下去；再改回来。

## 第 3–4 周：TISMIR 稿（Reading or remembering?）
五问：
1. F1 是怎么算的？"容差 ±2 小节"是什么意思？为什么容差一变结论就变？
2. "只给曲名"这个条件控制的是什么？"只给作曲家和体裁"又排除了什么？
3. 按比例猜的基线 0.28 是怎么来的？
4. 为什么说 GPT"没有读谱优势"，但精确到小节时又有？
5. 六条弱点里，哪一条最致命？补它要做什么实验？

动手：
- 第 3 周：挑一个乐章，自己手标奏鸣曲式边界，再和专家标注、模型输出对比，手算一次 F1。
- 第 4 周：两篇各做一次 10 分钟脱稿讲解，录音，自己听一遍。

## 过关
两篇各五问全过 + 两次脱稿讲解 → 第一批套磁信（Teng、Agres、Di Liberto、Casey）才发。
