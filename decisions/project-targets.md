## 逐个说

### EEG 论文
- 有用的最低线不是"投出"，是"投出一篇审稿人不会在第一条就要求重做的"。所以 10 人全跑是底线。
- 对工作的用处被低估了：BCI 岗位任职要求（上海、西安、复旦 RA 等 ✅）列的就是 EEG 预处理、滤波、时频分析、Python / MATLAB、解码模型、范式经验。这篇论文一条条对得上，缺的只有"范式经验"（MI / P300 / SSVEP）。
- 对博士的用处是入场券，不是加分项。

### Shimon 观众研究
- 检索没找到任何"机器人 vs 人类演奏者"的观众 EEG 研究 ✅；最近的是 Tervaniemi 2022（音乐会观众 EEG，人类演奏者）、NEUROLIVE（Goldsmiths，多人同步 EEG，舞蹈与音乐会）、Rai 2022（移动 EEG 同场最多 23 人，总 N=69，舞蹈）。
- 所以它的问题是真空位。慢是它唯一的毛病。
- 最低线是 protocol + 10 人 pilot，这样 2027-12 的 HRI LBR 能投；完整论文博士阶段再说。

### robot pet
- Blossom（Hoffman 组，THRI 2019）的评估是儿童科学日展出和中学工作坊，不是 Godspeed 对照实验 ✅。这意味着"设计贡献 + 现场使用记录"在 HRI 顶刊是成立的论文形态。你的"十人三问"够作品路线，加一次公开展出（Listening Machines、GT 开放日）就够一篇短文。
- 对工作：具身智能岗位要求（猎聘、北京人形中心、清华深研院 ✅）= Python / C++、ROS / ROS2、机械臂真机调试、模仿学习（ACT、Diffusion Policy）、VLA。pet 覆盖前三项。如果想对口，第五步"空闲行为"可以用一个小的模仿学习策略做，顺手补第四项；不想就别加。广州本地岗位少（检索只见一条，要博士）⚠️。
- NIME 更正：NIME 没有独立 demo 轨 ✅；demo 是接收论文的附带选项，装置走 Music 轨。所以 pet 投 NIME = 2000 词短文 + 现场 demo，或 Music 轨装置。截止历年 2 月初。

### 音乐表演分析 Agent（perfagent）
- 新先例 ✅：MuseAgent-1（arXiv 2601.11968，2026-01）= 大模型 + OMR + AMT + 谱音对齐，MuseBench 含表演层分析。另有 EU 项目 PPA（谱 + 录音 → 起音 / 力度 / 速度）和 Jiang 2022（Sonic Visualiser 改造，自动对齐后显示速度）。
- 结论：**"做一个会看谱会听的 Agent"这件事已经有人做了**。守得住的仍是你原来写的两条：研究 1 对齐误差怎么传到音乐学结论（没人量化），研究 2 Agent 分析的编造率（没人测）。Agent 本体退为工具，论文是评测。
- 对两条博士主线不加分，这一点不变。

### 钢琴视觉化教育系统
- Music Paint Machine ✅：12 个一二年级孩子学单簧管九个月，6 人用系统 6 人不用，Gordon 音乐听想测验前后测，无显著差异（Nijs & Leman 2014）。作者自己的结论是前后测设计不够。
- 所以你的实验设计必须比它好在两点：测的不是"音乐能力"而是"表达探索"（可以是过程指标：力度范围、速度变化、尝试次数），以及撤掉画面后的保持。否则就是第二个阴性。
- Monash 2024 ✅（ICCC，MIDI → 情绪与结构 → 实时图像，面向音乐人灵感）证明"实时"可做，但对象是成人音乐人。

### measure-numbers、捏握乐器、微分音机器人、终极 A / B
见表。measure-numbers 已过线；捏握乐器的产品面是三条创业候选里唯一实的；微分音机器人纯作品；终极 A / B 在硕士阶段只需要写成 SoP。

## 两句总结
- **对博士**：导师要看的是"你主导并做完了什么"。能在 2027-09 前满足这一句的只有 EEG 论文、pet 视频、measure-numbers，加上 Shimon 的 protocol + pilot 作为"导师项目里你的角色"。
- **对工作**：BCI 岗位看 EEG 论文那套技能；具身岗位看 pet 那套技能加 ROS2 / C++ / 模仿学习；音频算法岗看 DSP / C++ / ISMIR 论文，你的项目里没有一个给 C++。C++ 和 DSP 还是 profile.md 里那条技能缺口，项目补不了，得单独练。
