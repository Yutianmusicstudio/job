## 这条信号改变什么
1. **项目的就业价值 = 可迁移技能 + 学位标签，不是项目本身。** 这与 `project-targets.md` 的结论一致，但更狠：连 Shimon 这种级别的项目都不直接换工作。
2. **GT 直博的"保底"要加一个条件。** 名额和经费之外，博士课题必须含一项可出口的技能：EEG / BCI 的信号处理与解码，或 ROS2 / C++ / 模仿学习的机器人工程。纯"乐器机器人"课题不接。写进 Gate A 的条件。
3. **"单独练 C++ / DSP / LeetCode"从技能缺口升为日程项。** 项目补不了，每周固定时间。具体排法另定，不挤 PeerJ。
4. **pet 的就业价值取决于工程选择。** 用 ROS2 写、用 C++ 写节点、动作原语用模仿学习做一小块，才算具身岗位技能；用 Python 脚本把它做完，就只是作品。
5. **两张标签策略是对的，而且更紧迫。** 对外永远是"BCI / 神经解码"或"HRI / 具身智能"，"机器人音乐"只在音乐学院和作品集里用。
6. **音乐学院教授这条路要正视名额。** 星海一年一两个岗，乐器机器人博士找不到工作的一部分原因就是对口岗位极少。所以 (a) 不能当主路，只能当两条线顺带能到的地方。
