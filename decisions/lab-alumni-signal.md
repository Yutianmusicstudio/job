- 实验室其他找到工作的毕业生，靠的都是项目之外自己另有的能力。
- 实验室项目本身对就业没有多大帮助。
- 检索未找到 Weinberg 组博士去向的公开汇总 ⚠️（一次检索），所以以上只是一个样本加几个旁证，不是统计。

## 这条信号改变什么
1. **项目的就业价值 = 可迁移技能 + 学位标签，不是项目本身。** 这与 `project-targets.md` 的结论一致，但更狠：连 Shimon 这种级别的项目都不直接换工作。
2. **GT 直博的"保底"要加一个条件。** 名额和经费之外，博士课题必须含一项可出口的技能：EEG / BCI 的信号处理与解码，或 ROS2 / C++ / 模仿学习的机器人工程。纯"乐器机器人"课题不接。写进 Gate A 的条件。
3. **"单独练 C++ / DSP / LeetCode"从技能缺口升为日程项。** 项目补不了，每周固定时间。具体排法另定，不挤 PeerJ。
4. **pet 的就业价值取决于工程选择。** 用 ROS2 写、用 C++ 写节点、动作原语用模仿学习做一小块，才算具身岗位技能；用 Python 脚本把它做完，就只是作品。
5. **两张标签策略是对的，而且更紧迫。** 对外永远是"BCI / 神经解码"或"HRI / 具身智能"，"机器人音乐"只在音乐学院和作品集里用。
6. **音乐学院教授这条路要正视名额。** 星海一年一两个岗，乐器机器人博士找不到工作的一部分原因就是对口岗位极少。所以 (a) 不能当主路，只能当两条线顺带能到的地方。

- 不因此放弃 GT 直博选项，只是加条件。

## 第二轮（2026-10-22）：我的澄清 + 国内教职的现实
我说：国内音科在发展，读完四年博士总会有学校要；我之前的意思是 Shimon、guitar bot 和一些莫名其妙的论文偏艺术，大厂肯定不要。

Claude 的判断：
- 同意"偏艺术的不要"。但要分开：**"造一个新乐器机器人"的课题**偏艺术，大厂不要；**Shimon 观众 EEG 研究**不是，它是一个 EEG 实验，壳是音乐，可出口的是 EEG 分析。前者不接，后者留着。
- "总会有学校要"：**对一半**。对的一半：音科学科在铺开（2025-12 长沙学院研讨会，央音 / 国音 / 上音 / 中传 / 浙音 40 余人到场 ✅），地方和应用型院校在建系，缺人。不对的一半：2024 年博士毕业 9.72 万，高校各类岗位合计约 3.5 万（单一学者估算，未核 ⚠️）；35 岁门槛常见；部分校非升即走、部分校给编制（杭电 2025 明确有编制 ✅）；没查到 2025–26 新增音科博士点 ⚠️。
- 换句话说：**"有学校要"≈ 地方院校；"星海"≈ 几年一个岗**。前者是保底，后者是目标。
- 这不改变结论，反而加固：课题要"工程内核 + 音乐外壳"，两张标签同时成立。国内四年博士对音科教职可行，但同一个四年如果课题是艺术向的，出来只有教职一条路，没有大厂退路。

## 第三轮（2026-10-22）：这是交互实验室，不是机器人实验室
我说：他们今天一直强调，这根本不是 robotic lab，是交互实验室。

这句话把前两轮解释通了：
- 毕业生靠"项目外的能力"找工作，是因为交互实验室产出的是交互研究，不是机器人工程。做机器人的博士出来没有机器人岗位要的技能，是结构性的，不是个人问题。
- 所以"工程内核"不能指望 lab 给，要自己配：机器人课程、IRIM、C++ / ROS2 固定时段。这条已经在日程里。
- 但交互实验室有一条我之前没算的出路：**大厂的人机交互研究岗**。华为有 Human-Machine Interaction Lab，招 HCI researcher，看作品集、论文、专利、上线产品 ✅；联想有 HCI 研究岗（要 3 年经验）✅；腾讯 / 字节未检到具体岗位 ⚠️。这条路不走 MIR、不要求 ROS2，要的是用户研究方法 + 原型 + CHI / HRI / NIME 论文。这正是 lab 能给的。
- 修正两条目标的映射：
  - 音乐学院教授 ← 交互研究 + 作品（lab 原生，最顺）。
  - 大厂 ← 两条：具身智能工程（lab 不给，自配）或 **HCI 研究岗（lab 给）**。后者是新加的，而且更顺。
- 三张标签：BCI / 神经解码；HRI；HCI / 人机交互研究。pet、视觉系统、捏握乐器、Shimon 观众研究，全部能用第三张标签讲。
- 候选导师的口味也要按"交互"重读：Hoffman（HRI）、Bresin（声音交互）、Machover（交互乐器）、Xiaojuan Ma（HCI）都是交互人，这说明候选表本来就对；Shamma、华工 BCI 是工程人，是另一张标签。
