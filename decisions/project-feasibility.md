## 读法

### 2027-03 前真正能"做出来"的只有三个
PeerJ 投出、measure-numbers（已完成）、pet 视频。Shimon 在 2027 年底前不会有完整结果。其余全是条件触发或排队。这与 `priorities.md` 的槽位一致：两篇论文一个 demo。

### 去处分四种，别混
1. **论文会议**：PeerJ、Shimon、perfagent 研究 1、视觉系统（有 PI 时）。慢，但对博士申请和回国科研院所唯一有效。
2. **作品 / demo 场**：pet、measure-numbers、捏握乐器、微分音机器人。NIME demo、TENOR、TEI、Listening Machines、Guthman。快，决定导师看到你时的第一印象。
3. **产品 / 创业场**：measure-numbers（已上线）、捏握乐器、perfagent 产品面、视觉系统。CREATE-X Startup Launch、I2P。只有捏握乐器像能卖的东西；其余是工具或研究。
4. **人**：每个项目最后一栏。项目做出来的那一刻就该变成一封邮件，附链接，发给那一栏的人。

### 每个项目一句话风险
- PeerJ：唯一风险是你继续拖。它卡的是写作，不是研究。
- Shimon：最可能"做了很久、2028 申请时仍没结果"。所以它的价值提前兑现方式是 protocol + pilot 做 LBR，不等完整论文。
- pet：SO101 的物理上限决定了它只能是"时机与配合的表达"，这正好是 Hoffman 一派的口味；别去和速度快的机器人比。
- perfagent：最容易膨胀。研究 1 不需要 Agent 本体，先做研究 1。
- 视觉系统：命运由一次会议决定，不由工程决定。
- measure-numbers：别续做；TENOR 投了就算最后一步。
- 捏握乐器：是三条创业候选里最像产品的，但"疗效证据"那半需要你没有的临床合作。先做物件。
- 微分音机器人：纯作品，职业价值低、乐趣高。排 pet 之后不插队。
- 终极 A / B：在硕士阶段的用途是"写进 SoP 的研究计划"，不是做出来。

### 对博士申请的直接映射
- 神经线材料：PeerJ（已有）+ Shimon（进行中）+ 终极 B（计划）。
- 具身线材料：pet（视频）+ 微分音机器人（视频）+ 终极 A（计划）。
- Machover / 健康线：视觉系统 + 捏握乐器。
- 计算音乐学 / 港科广：perfagent + measure-numbers。
- 2027-09 Gate C 前至少要有：一篇投出的论文（PeerJ）、一个三分钟视频（pet）、一个在线工具（measure-numbers）。这三样现在都在你手里。
